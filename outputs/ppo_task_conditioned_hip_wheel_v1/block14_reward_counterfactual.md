# Block14：相同真实状态的反事实 reward 核验

仅离线计算，不是新 rollout、GAE、策略干预或 optimizer 重放；候选参数未改。
输入为封存 block14 的 512 个实际决策末端物理快照。完整旧
`physical_potential` 在 512 点均复现日志，511 对相邻状态的完整旧 shaping
亦复现。第一个决策之前的物理快照未存，未编造其新 reward。

计算使用现有全身组合函数（所有四腿与 finish），不是单腿 retention
代替全身 Phi。公式为 `5 × (0.9985 × Phi_after − Phi_before)`；gamma 每次
policy decision 使用一次，实际每段 dt=8/120=0.0666667 s。原日志无终态；
普通阶段切换保持非终态。现有每腿 capture 份额为 `.85/4×.2=.0425`，
不是新增 bonus。系数来自该 run 已哈希核验的 reward 与实际 runner 配置。
