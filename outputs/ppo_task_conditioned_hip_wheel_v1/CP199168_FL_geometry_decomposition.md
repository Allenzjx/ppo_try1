# FL未落脚：局部扰动有效，但只补了约2.25mm的真实缺口

只读成功B、CP199168 det及已封存hip−1°/knee+1°诊断；没有新物理/训练。下面是实测几何恒等式分解，不是同状态动力学反事实，也不主张复制B姿态。

## 这次小扰动为什么只改善2.25mm

干预前3256tick状态已在原报告逐拍核验一致。hold3353–3856同时间比较中，实际hip平均变化 **−1.0085°**、knee **+0.9561°**，对应：

`gap差 −2.2534mm = 安装点世界z差 +0.1833mm + 相对轮端构型项 −2.4727mm + 机身朝向项 +0.0360mm`。

构型项按“以对照当拍机身朝向旋转实测轮底相对FL安装点向量差”定义；朝向项补齐该恒等式。它包含闭环后的实际轮端几何，**不能单独归给hip、knee或其他通道**。安装点微升和姿态变化共抵消约0.219mm，主体并非机身下沉。小幅双关节扰动真正产生的局部下移约2.47mm，本来就小于对照hold平均8.643mm gap，最后仍平均6.390mm、最小4.653mm，无任何FL接触。

不是动作被拒：3856同拍N=22.8/−13.4°；诊断mapped=22.212/−12.150，REQUEST=effective=−4.981/−7.608，final=17.231/−19.758，actual=17.719/−19.754。对照actual=19.046/−20.581。无两通道clip，另10维人工增量为0；两轨迹的mapper/在线策略反馈可以不同，因此不能把final差全部当作当拍PPO修正。

## 重建验证与缺失

传感器记录明确来自body_link_pos/quat。重建FL安装点与probe独立fourhip在3256/3352/3856逐值相等（误差0）；B与probe初始13刚体、关节、轮/碰撞体几何、CoM/障碍全相等。再以初始FL upper局部点核对关节连接，B选定状态最大误差4.40e−8m，新窗口最大1.38e−7m。B本身没有直接FL四髋日志，直接记录字段仍null，推导来源明确保留；不能把重建说成B当时另有安装点传感器。

没有记录FL knee轴/枢轴或FL Jacobian，因此**独立hip/knee瞬时竖向导数为null**。没有拟合关节轴、补造FK梯度或预测接触成功。当前结论仅是：动作实现了有限局部下移，但全身几何入口仍与成功状态不同；释放后没有建立接触/保持。无新aux标签、无训练信用。
