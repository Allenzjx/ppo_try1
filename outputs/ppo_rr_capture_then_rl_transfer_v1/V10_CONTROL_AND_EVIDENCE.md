## 已实施的动作顺序

```text
真实 RR 卸载/抬升、越沿
  → 合法 XY + 其他实际支撑 + 可跟踪关节 → hip 负向有限搜索
  → hip 搜索后 knee 有限下降
  → 每次真实下降≥0.2 mm 获得短窗继续资格
     （v10 不再要求已经进入 TOP 判定用的 +25 mm 区域）
  → 真实传感器 TOP 接触 → captured-follow，继承已发 nominal/request 增量
  → RR/FL 等当前支撑与 FR 接收准备 → RL 任务
  → RL 实际放置 → RR 辅助平滑退出 → 终态
```

最后两行是后续任务，不代表本轮新版本已完成。当前生产仍有原 RL 接续，没有新增 FR/FL 重构 owner 或独立 RL 暂停时钟。
