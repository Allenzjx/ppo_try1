# 正式 C170240 与 C168192：P01–P02 集中对比

只读共同 episode tick 0–752（120 Hz）及各自真实末点；新 C 为 a9c/170240、752 ticks（6.2667 s），旧 C 为 dbc/168192、887 ticks（7.3917 s）。两次均 P02 HARD_JOINT_LIMIT，FR 有抬升历史但未跨前缘/放置。未读活动 B、未加载模型、未做仿真或生产修改。

## 第一明确分歧与执行链

初始实际 q/qd、轮状态、base、CoM、contact 和几何 bounds 完全相同。752 个共同控制 tick 的 source N 全部相同。两者均：几何修正相对 mapped N 为 0、controller bias 为 0、headroom clip 为 0、all12 mask 为 1、native dispatch 验证通过；实际 native target 转 canonical 与物理日志 target 最大差 ≤1.703e−6。

12 路 raw 在 tick1 已不同；最终 target 首先在 tick1 的 RL knee/RR hip/RR knee 不同，四轮 target 最早在 tick2 不同。各路实际运动、接触力与 base 在 tick1 已出现数值差异；RR actual 差超过 0.1° 的第一个点为 tick11。之后只能比较相同时间坐标，不能称相同物理状态对照。

## 实际高度、接触与四轮

RR 在两者全部 753 个共同物理点都是真实、pair-verified GROUND；没有 RR 障碍物接触。tick400 的 FL/RL/RR normal force 为新 11.652/3.392/13.745 N、旧 11.666/3.334/13.677 N。不是“RR 先完全失去接触”这一链。

共同 P02 的四轮 target 均值（FL/FR/RL/RR，rad/s）为新 [−0.1105, 0.0325, 0.0533, 0.7561]、旧 [−0.0876, 0.0601, 0.1239, 0.7598]。目标共同分量均值从 0.2141 变为 0.1828，差动 RMS 均值从 0.3244 变为 0.3370；变化不只是 RR wheel。实测速率、轮体线速度及各腿实测载荷见 JSON，但尚未做扭矩/载荷时序因果分解。

新 FR 早期最大净空 91.94 mm（旧 83.98 mm），并未转为 crossing。tick752：新/旧 base origin 高度 46.00/53.55 mm、CoM 高度 115.65/125.78 mm、FR 净空 −6.83/+6.30 mm。各自末点 FR 净空 −6.83/−15.82 mm，都没有跨沿和放置。base origin 不是机身碰撞最低点：新 terminal 真实最低 collider 高度 62.00 mm，独立 fresh bounds 与原评价一致，body collision=false。

## 驱动设置与力矩可观测边界

新 C tick0 fresh PhysX getter 确认：8 servo K=600、D=60、max force=2.700000048 Nm、max speed≈5 rad/s；4 wheel K=0、D=20、max force=1 Nm、max speed=2.094395 rad/s；读取前后时钟未变、无 setter/reset/step。未发现配置错配。旧正式 C 未保存这些 getter/effort，不能用旧诊断的 getter 代替。

新 C 的 94 个每8tick保存的 RR implicit estimate（t8…752，含92个 P02-request端点）全部被裁到 native −2.7 Nm；未裁估算范围 −613.679…−4.462 Nm。使用真实 t−1 position/velocity 与 t native target 的 KΔq−Dq̇ 重构，最大差 4.71e−5 Nm，说明该估算与目标/符号/时钟链一致。四轮同类估算超限端点数为 [93,0,12,82]/94。

这不是独立测得的 PhysX motor torque，也不是对每个未保存中间 tick 的连续实测。旧 wheel4-off 诊断同样曾有早期 RR 估算裁剪、随后恢复并到达 FR placement，因此“估算裁剪”本身不构成充分原因或加 gain 的依据。

两个正式 C 的全部已返回 P02 endpoint motion fraction 都为 1，不支持重复 functional-carry 折扣。下一最小方向仍是比较成功随机训练 sample 与 old conditional mean/std、确定性轨迹覆盖及全身轮速/承载演化；本结果不支持永久 mask、擅改物理增益或声称唯一根因。
