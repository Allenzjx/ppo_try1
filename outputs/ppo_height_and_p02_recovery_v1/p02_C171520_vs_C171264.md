# C171520 与 C171264：同 N 的早期跟踪差异

两次正式 all12 deterministic 评估都有相同的 eec6 源码与 runtime 摘要。tick0 记录的实际 Full12、关节位置/速度、base、CoM、接触、body bounds、wheel 几何全部精确相同，数字 maxabs=0；共同 tick1–693 的 **693 条 source nominal Full12 全部相同**。这不是把相同 seed 当成相同初态，也不声称检查了未记录的 PhysX 隐状态。

首条 tick1 的 12 个 raw conditional mean 全部已有差异。FR knee、RL knee、RR hip/knee 的 final target 亦在 tick1 不同；其余伺服目标在 tick2–4 才不同。四轮 final target 的首差异 tick 为 FL/FR/RL/RR = **5/2/2/6**。但是 tick1 四轮目标两次完全相同 `[-.015,-.015,-.015,+.015] rad/s`，实测轮速已不同（RL 新 −.01957、旧 +.01923 rad/s）。同 tick1 多个腿目标已变，所以不能将时序简化成“轮目标先变导致 RR”，也不能从这里分离全身载荷/驱动影响。

RR knee 的实际-目标误差持续至少 12 个 tick，首次达到 1°/2°/5°的起点：新 **29/44/63**，旧 **30/46/67**。这些仅是诊断阈值，不是成功判定或训练门槛。

新目标略不那么弯曲，实际却更弯。共同窗口 RR 单 tick 同 prestate residual 目标作用约 −0.36 至 −1.52°，不是 −60°目标。两次 693/693 native dispatch/counterfactual 与 all12 mask 验证通过，controller bias=0、geometry correction 与其 native-drive 对照差=0、记录的 policy-headroom clipped channel-ticks=0。未见这些字段支持新增重复派发/单位错配解释；这不等于实际负载下的驱动能力已充分。

共同 P02 的四轮目标平均值（FL/FR/RL/RR，rad/s）：新 `[-.16872,.03740,.01846,.77564]`，旧 `[-.17889,.04809,.04203,.77595]`。共同模式均值新 .16570、旧 .17179；差分 RMS 均值新 .36128、旧 .36063。不是一个孤立通道或纯 common-mode 对照，不能据此选择唯一轮子根因。

tick693 新/旧 base 原点高度 48.206/50.762 mm，raw CoM 高度 116.582/122.530 mm，FR 对 top 净空 −5.570/+9.092 mm。RR 在共同 694 个观测 tick 始终有已验证 ground 接触，未记录 RR obstacle 接触；接触力存在，但本次未做腿载荷与瞬时关节力矩的时序因果分解，也未重新估算或测量驱动力矩。

两次 FR Q 均在 tick25 获得，但无 crossing/placement。CP171520 在 tick693 / 5.775s、CP171264 在 tick751 / 6.258333s 因 P02 RR knee HARD_JOINT_LIMIT 中止；后者真实终态 target/actual 为 −5.2940°/−60.0075°。首个未完成任务均为 FR 越过前缘，终态未检出机身碰撞。缺失的未返回最后决策奖励不补造。

因此确认的是：同初态、同 N，更新后冻结均值产生不同的早期全身动作并继续表现为 RR 跟踪崩塌；本次结果**没有证明 sigma 是根因**。温度修订仍只能作为后续均值邻域采样候选，其实际学习结果另看完整训练和重载评估。

证据：同目录 `p02_C171520_vs_C171264.json`。复用两个正式 evaluator receipt，只读取两次已封存的共同前 693 tick 与旧终态尾点；未读取活动温度训练、旧 154MB 训练日志或 checkpoint tensor，未改生产、未启动仿真。
