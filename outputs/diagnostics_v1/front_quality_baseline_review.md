# 前腿质量只读基线：先保任务，不据此调 reward

本次只读取两个指定的**已封存**轨迹，未扫描其他 Recording，未读取活动 zero v2，未启动 Isaac、PPO 或修改生产代码。完整数值和窗口定义在同目录 `front_quality_baseline_review.json`；可复现脚本为 `review_front_quality_baselines.mjs`。

这里的 zero 是新相机下 **zero refinement v1**（3d231，8857 ticks，最终速度验收失败），不是被保护的原 73.808 秒成功 zero。PPO 是**历史 CP177152**（00050a，6116 ticks），历史成功记录保留，但现为 `RR_ACCEPTANCE_UNDER_REVIEW`；既不是最新 CP177792，也不是新严格 RR 成功。不同版本、仅各一条轨迹，不给整体稳定性改善率或因果结论。

## FR 抬升：向 RL 方向移动 ≠ RL 正在承载

共同初始窗口为 tick0–120，即真实 0–1 秒，各121个物理观测；当前接触/载荷另取15个已记录 decision endpoint，不插值。

| 初始1秒测量 | zero v1 | 历史 CP177152 |
| --- | ---: | ---: |
| roll RMS | 7.652° | 7.281° |
| pitch RMS | 6.265° | 6.254° |
| roll 峰峰幅度 | 13.783° | 13.880° |
| pitch 峰峰幅度 | 10.145° | 10.641° |
| CoM 沿起点“CoM→RL轮心”固定 XY 方向的净投影 | +37.20 mm | +36.27 mm |
| 当前 RL 已验证承载样本 | 3/15 | 2/15 |
| 当前 RL AIR 样本 | 12/15 | 13/15 |
| RL 平均载荷比例 | 0.0140 | 0.0116 |

两条轨迹中 CoM 均朝起始 RL 几何方向移动，但 RL 大部分采样仍为空中。与此同时 RL 自身轮心在世界坐标中也移动，真实 CoM–RL XY 距离分别**增加47.78/49.10 mm**；因此不能把固定方向投影说成“CoM 已更靠近当前 RL 接触点”，更不能说“RL 已承担这部分载荷”。

直到首次 FR 放置的完整窗口，zero 为0–12.516667秒，CP177152为0–11.641667秒：roll RMS 分别13.284°/13.370°，pitch RMS为10.512°/11.147°。窗口时长不同，仅描述现象；不能由这些数值推出最优 CoM 目标、必须更早压 RL，或某个关节/轮子造成了摇摆。FR 初始离地与四腿共同动作仍需按真实接触、几何和运动事件解释。

## 前双腿放置后：区分历史事件、当前接触和轮心高度

以两前腿历史 placed 均已发生的首个 tick 为共同锚点，再观察固定1秒：zero tick2677–2797（22.308333–23.308333秒）；CP177152 tick2648–2768（22.066667–23.066667秒）。两者均121个120Hz物理样本。这个锚点**不假定此后两腿持续承载**，也不新增必须停稳的阶段门槛。

| 同事件后1秒测量 | zero v1 | 历史 CP177152 |
| --- | ---: | ---: |
| 当前两前轮同时为已验证 TOP 承载 | 121/121 | 42/121 |
| 已记录 evaluator 同时 TOP 承载（独立核对） | 15/15 | 5/16 |
| FR AIR（已记录 evaluator） | 0/15 | 10/16 |
| FR−FL 轮心 z 高度差，均值 | −0.565 mm | +0.551 mm |
| 轮心高度差绝对值 p95 | 1.015 mm | 3.148 mm |
| FR collider 最低点减平台顶面，最大值 | +0.016 mm | +3.623 mm |
| 同时 TOP 承载时，实际接触点 z 差绝对值 p95 | 1.221 mm（121样本） | 1.563 mm（42样本） |
| roll 峰峰幅度 | 0.426° | 1.346° |
| pitch 峰峰幅度 | 1.997° | 0.915° |
| roll 速率绝对值 p95 | 2.816°/s | 7.790°/s |
| pitch 速率绝对值 p95 | 11.726°/s | 2.329°/s |

CP177152 在这个窗口有更大的 roll 变化和短暂 FR 离面，而 zero 的 pitch 变化更大，不能归纳成一方“全面更平稳”。历史 placed 后重新卸载可能属于合法连续支撑重分配；是否不必要必须结合后续任务效果，不能直接增加固定支撑组合或静止门禁。

两轮面对的**平台顶面均为同一 z=0.05m 平面**。轮心 z、随姿态变化的 collider 最低点 z、实际 ContactSensor 平均接触点 z 是三个不同量。毫米级轮心差不等于两只轮接触了不同高度的平台；轮子姿态、碰撞体几何、接触变形/数值误差和离面均可能影响读数。表中接触点差仅统计两侧均有当前 TOP 承载证据的行，悬空时不虚构接触点。

## 下一步使用边界

先完成严格 RR 任务修复与真实 P01 评估，quality epsilon 仍为0。之后可以在同任务达成条件下复用这些固定窗口，检查 FR 抬升是否存在不必要姿态幅度，以及两前腿放置后是否能保持足够净空/前送并减少额外摇摆；本报告不指定唯一动作、CoM 位置或永久支撑组合。

附加解释：现有 FR transfer-role 的 `load_fraction_change` 实际是**FR 在短窗内减载量**，不是 RL 载荷增加量；JSON 已将该字段明确命名为 `recorded_FR_role_local_window_FR_load_drop`，RL 的真实承载力和载荷比例单列。所有统计是描述性相关，不是力学最优性或单一动作因果证明。
